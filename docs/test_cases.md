### 1.2 用例编号与优先级

- 编号规则：`TC-{模块}-{两位序号}`，模块码见各节标题。
- 优先级：
  - **P0** 核心路径，失败即阻塞发布；
  - **P1** 重要功能与回归点，发布前必须通过；
  - **P2** 次要功能、体验与健壮性，允许带问题发布（需记录）。
- 每条用例含：前置条件、测试步骤（①②③表示顺序动作）、预期结果。
- 步骤与预期中的"列表"均指"任务管理"页表格。

## 2. 通用前置条件

1. 被测程序为本仓库源码运行（`run.py`）或 v2.4.0 安装版；数据目录 `%APPDATA%\TaskReminder`。
2. 自动化用例使用 conftest 独立临时库；人工用例建议使用干净的测试库（或先备份真实数据）。
3. UI 人工用例在**真实 Windows 桌面**执行（offscreen 仅用于自动化，中文渲染为方框属正常）。
4. 时间相关用例可通过把任务的提醒时间设为"当前时间-1 分钟"来构造"下一轮询立即触发"。
