# 任务提醒助手（TaskReminder）需求文档

版本：v2.0（需求基线）
日期：2026-09-05
状态：v1.0 已交付；本文档为 v2.0 开发依据。

---

## 1. 项目概述

### 1.1 背景
功能完整、用户友好的**单机版桌面任务提醒软件**，面向个人/小团队本地任务管理与到期提醒，不依赖服务器。

### 1.2 已确认决策
| 项 | 决策 |
|---|---|
| 技术栈 | Python 3.10 + PyQt6（跨平台框架）+ SQLite + PyInstaller，**继续沿用，不迁移 Electron** |
| 平台 | Windows 10/11 **64 位**（PyQt6 无 32 位包，32 位不在支持范围；源码本身跨平台） |
| Git | 仅做**代码托管**（本地提交 + 远端同步），不做应用内 Git 功能 |
| 界面语言 | 简体中文 |

### 1.3 版本规划
| 版本 | 内容 | 状态 |
|---|---|---|
| v1.0 | 任务管理、查看检索、本地提醒、备份恢复、安装包 | 已完成，tag `v1.0` |
| v2.0 | 数据模型扩展、表格与编辑升级、搜索增强、提醒增强、Excel 导入导出、10 万条性能、覆盖率≥80% | 本文档定义 |

## 2. 功能需求

### 2.1 任务管理（v2.0 增强）
- FR-1.1 新建任务字段：**任务名称**（文本，2–50 字符）、执行人（2–50 字符）、**任务内容（富文本，多行，最大 5000 字符，支持加粗/斜体/下划线/列表等基本格式）**、截止时间（精确到分钟）、提醒时间（精确到分钟，**必须早于截止时间**）、状态、备注。
- FR-1.2 编辑：**双击表格行或编辑按钮**进入编辑，全程字段校验（长度、必填、时间先后关系）。
- FR-1.3 删除：二次确认。
- FR-1.4 状态：未开始/进行中/已完成；**状态变更记录时间戳（status_changed_at）**；支持下拉/标签快速切换。

### 2.2 任务查看与检索（v2.0 增强）
- FR-2.1 表格列：**任务名称/摘要**、执行人、截止时间、提醒时间、状态、**操作按钮（编辑/删除）**；备注列默认隐藏可开启。
- FR-2.2 **列宽调整、列显示/隐藏、列顺序自定义均持久化**（重启恢复）。
- FR-2.3 多维排序：截止时间/提醒时间/状态/执行人（升降序），**表头箭头可视化**，状态栏显示当前排序，排序状态持久化。
- FR-2.4 高级搜索：执行人精确匹配、内容关键词模糊、**创建时间范围**、截止时间范围、状态筛选；**关键词输入实时防抖更新（300ms）**；**支持保存/加载/删除常用搜索条件**。
- FR-2.5 分页浏览；操作响应 ≤300ms。

### 2.3 提醒功能（v2.0 增强）
- FR-3.1 本地提醒：到达提醒时间立即触发（前台/后台/托盘均生效），延迟 ≤10s。
- FR-3.2 提醒方式：模态弹窗（任务详情预览 + 稍后提醒/标记完成按钮）+ 声音（**内置 3 种音效** + 用户自定义本地音频）。
- FR-3.3 去重与跨日重置（沿用 v1.0）。
- FR-3.4 提醒历史：记录提醒时间、任务快照、**用户响应操作（稍后/标记完成/关闭）及响应时间**；**支持按时间范围查询**，可清空。

### 2.4 数据管理（v2.0 增强）
- FR-4.1 SQLite 持久化；schema 含任务表、提醒记录表、**用户设置表**；软件正常关闭/崩溃后数据不丢失（事务化写入）。
- FR-4.2 备份/恢复：JSON 导出导入、整库复制（沿用 v1.0）。
- FR-4.3 **Excel 导出（.xlsx）**：导出范围可选 **全部任务 / 选中任务 / 当前筛选结果**；列与界面一致；导出完成提示并可打开目录。
- FR-4.4 **Excel 导入（.xlsx）**：字段校验（必填、时间格式与先后关系、长度）；**冲突处理**（同名+同执行人+同截止视为重复，可选择跳过或覆盖）；导入结果汇总报告（成功/跳过/失败条数）。

### 2.5 交付与部署
- FR-5.1 独立运行桌面应用，无需预装环境；**Windows 64 位**。
- FR-5.2 安装包 TaskReminderSetup.exe：图形安装、快捷方式、程序组、卸载条目，**支持静默安装**。
- FR-5.3 便携版 onefile exe。
- FR-5.4 用户手册（图文、FAQ、**提供 PDF 版本**）、测试报告。

## 3. 非功能需求

### 3.1 性能（10 万条任务数据）
| 指标 | 目标 |
|---|---|
| 冷启动 | ≤ 5s；热启动 ≤ 2s |
| 提醒触发延迟 | ≤ 10s |
| 单条任务检索 | ≤ 100ms |
| 复杂条件查询 | ≤ 1s |
| 翻页 | ≤ 300ms |
| Excel 导出 10 万条 | ≤ 30s，不阻塞 UI |

### 3.2 稳定性
- 连续运行 24h 内存增长 ≤10%；空闲 CPU <5%；搜索/排序 CPU 峰值 <50%；无内存泄漏。

### 3.3 UI/UX
- 现代简洁风格，浅色/深色主题；视觉层次清晰。
- 最小窗口 800×600；支持字体大小调整；界面个性化（列顺序/显隐/宽度记忆）。
- 高 DPI 适配（100%/125%/150%）。

### 3.4 质量保障
- pytest 覆盖率 ≥80%（pytest-cov 统计）；性能基准入测试报告；兼容性覆盖 Win10/11 64 位。

## 4. 验收标准（v2.0）

1. 新建任务含名称与富文本内容，校验规则生效（名称 2–50、内容 ≤5000、提醒早于截止）。
2. 表格含名称/摘要与操作按钮列；列显隐/顺序/宽度重启恢复；双击行可编辑。
3. 表头排序箭头可见且正确；状态栏显示排序；重启恢复。
4. 搜索面板支持创建时间范围、实时更新、保存/加载搜索条件。
5. 触发提醒后历史记录含响应操作与响应时间；可按时间范围查询。
6. 内置 3 种音效可试听切换；自定义音效可用。
7. 导出：选中 3 行仅导出 3 行；筛选后导出行数与筛选总数一致；Excel 中文正常。
8. 导入：错误数据被校验拦截；重复数据按所选策略跳过/覆盖；结果汇总正确。
9. `seed_perf.py --n 100000` 后各项性能指标达标并记入测试报告。
10. `pytest -q` 全绿且覆盖率 ≥80%。
11. 安装包（64 位）干净环境安装/静默安装/卸载/启动验证通过。
12. git 全程提交，tag `v2.0`；代码同步至远端仓库。
